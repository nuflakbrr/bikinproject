## Astro Template Starter Kit

This is an [Astro](https://astro.build/) project bootstrapped with [`create-astro`](https://github.com/withastro/astro/tree/main/packages/create-astro), and generated using [**BikinProject**](https://nuflakbrr.github.io/bikinproject).

## Technologies Used

- [Astro](https://astro.build/)
- [React](https://react.dev/)
- [TailwindCSS v4](https://tailwindcss.com/)
- [Axios](https://axios-http.com/)
- [Prettier](https://prettier.io/)

## Features

The features included in this project template are:

- **Project Architecture**: Clear separation of components using the `Common` and `Mixins` patterns.
- **Modern Stack**: Using the latest versions of Astro, React, and Tailwind v4 integration.
- **Vite Performance**: Extremely fast development experience powered by Vite.
- **Dark/Light Mode**: Manual dark mode support saved in `localStorage` integrated with Tailwind classes.
- **Automated SEO & Sitemap**: Dynamic sitemap and SEO generator using custom scripts.

### Project Architecture

There are several important points regarding how to implement a proper project architecture. For this case study, I have created a customized blank project template that implements best practices for organizing a project architecture to keep it clean.

```
/
├── public/                 # Static assets (favicon, robots.txt)
├── scripts/                # Utility scripts (generate-seo.ts)
├── src/
│   ├── components/         # Astro/React components
│   │   ├── Common/         # Atomic/small components
│   │   ├── Containers/     # Page-specific section components
│   │   └── Mixins/         # Complex components (Navbar, Footer)
│   ├── data/               # Static data & Metadata (SEO)
│   ├── interfaces/         # TypeScript Interfaces
│   ├── layouts/            # Main application layout
│   ├── lib/                # Utilities & Library helpers
│   ├── pages/              # Astro File-based Routing
│   ├── providers/          # Head Providers (ThemeProvider)
│   ├── styles/             # Global CSS & Tailwind Entry
│   └── types/              # TypeScript type definitions
├── astro.config.mjs        # Astro configuration & Integration
├── package.json            # Dependencies & Scripts
├── tsconfig.json           # TypeScript configuration
└── README.md
```

#### UI Components

- **Common Folder**: Contains atomic components such as buttons, icons, or other reusable basic UI elements.
- **Mixins Folder**: Contains larger and more complex components that are combinations of several `Common` components, such as Navbar or Footer.
- **Containers Folder**: Separates large and unique section logic that isolates pages from repetitive components.
