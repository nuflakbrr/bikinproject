## Nextjs Template Starter Kit

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app), and generated using [**BikinProject**](https://nuflakbrr.github.io/bikinproject).

## Technologies Used

- [Next.js (App Router)](https://nextjs.org/)
- [React](https://react.dev/)
- [TailwindCSS](https://tailwindcss.com/)
- [Axios](https://axios-http.com/)
- [ESLint & Prettier](https://eslint.org/)

## Features

The features included in this project template are:

- **Project Architecture**: Clear separation of components using the `Common` and `Mixins` patterns.
- **Modern Stack**: Using the latest versions of Next.js and React.
- **Turbopack Build**: Extremely fast development experience.
- **Custom Hooks**: A collection of useful hooks such as `useDebounce`, `usePagination`, and `useSort`.
- **Dark/Light Mode**: Built-in support for `next-themes`.

### Project Architecture

There are several important points regarding how to implement a proper project architecture. For this case study, I have created a customized blank project template that implements best practices for organizing a project architecture to keep it clean.

```
/
├── public/              # Static assets (images, fonts, etc.)
├── src/
│   ├── app/             # Next.js App Router (Pages & API)
│   │   ├── api/         # API Endpoints (route.js)
│   │   ├── (auth)/      # Auth route groups
│   │   ├── (root)/      # Main page route groups
│   │   └── layout.jsx   # Main application layout
│   ├── components/      # UI Components
│   │   ├── Common/      # Atomic/small components
│   │   └── Mixins/      # Complex components (Common combinations)
│   ├── data/            # Static data & Metadata
│   ├── hooks/           # Custom React Hooks (JS)
│   ├── interfaces/      # TypeScript Interfaces
│   ├── lib/             # Utilities & Library helpers
│   └── providers/       # Wrapper providers for layout
├── eslint.config.mjs    # Latest ESLint configuration
├── jsconfig.json        # JavaScript path aliases configuration
├── next.config.js       # Next.js configuration
├── package.json         # Dependencies & Scripts
├── tailwind.config.ts   # Tailwind CSS configuration
└── README.md
```

#### UI Components

- **Common Folder**: Contains atomic components such as buttons, icons, or other reusable basic UI elements.
- **Mixins Folder**: Contains larger and more complex components that are combinations of several `Common` components, such as Navbar or Footer.

### Custom React Hooks

Several hooks are provided to speed up development:

- `useDebounce`: To handle inputs that require delayed actions.
- `usePagination`: To handle page navigation via query params.
- `useSort`: To handle data sorting logic.

## API Routes

[API Routes](https://nextjs.org/docs/api-routes/introduction) can be accessed at [http://localhost:3000/api/hello](http://localhost:3000/api/hello). This endpoint can be edited in `/src/app/api/hello.ts`.

The `/src/app/api` folder is mapped to `/api/*`. Files in this directory are treated as [API Routes](https://nextjs.org/docs/api-routes/introduction) instead of React pages.
