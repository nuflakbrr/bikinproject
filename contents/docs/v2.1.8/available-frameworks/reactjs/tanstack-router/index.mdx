## Tanstack Router Template Starter Kit

This is a [React.js](https://react.dev/) project bootstrapped with [`Vite.js`](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md). And generated by [`create-bikinproject-app`](https://github.com/nuflakbrr/create-bikinproject-app) CLI.

## Technologies Used

- [React 19](https://react.dev/)
- [TanStack Router](https://tanstack.com/router)
- [TanStack Query](https://tanstack.com/query)
- [TailwindCSS](https://tailwindcss.com/)
- [Axios](https://axios-http.com/)
- [ESLint & Prettier](https://eslint.org/)
- [Vite](https://vitejs.dev/)

## Features

The features included in this project template are:

- **Project Architecture**: Clear separation of components using the `Common` and `Mixins` patterns.
- **Modern Stack**: Using the latest versions of React 19 and TanStack.
- **File-based Routing**: Using TanStack Router for type-safe route management.
- **Automated SEO**: Automated script to generate SEO metadata (`scripts/generate-seo.ts`).
- **Custom Hooks**: A collection of useful hooks such as `useAxios`, `useDebounce`, and `useSort`.
- **Dark/Light Mode**: Built-in theme support with `ThemeProvider`.

### Project Architecture

There are several important points regarding how to implement a proper project architecture. For this case study, I have created a customized blank project template that implements best practices for organizing a project architecture to keep it clean.

```
/
├── public/              # Static assets (images, fonts, etc.)
├── scripts/             # Utility scripts (SEO generation)
├── src/
│   ├── components/      # UI Components
│   │   ├── Common/      # Atomic/small components
│   │   └── Mixins/      # Complex components (Common combinations)
│   ├── data/            # Static data & Metadata
│   ├── hooks/           # Custom React Hooks (TS)
│   ├── interfaces/      # TypeScript Interfaces
│   ├── lib/             # Utilities & Library helpers
│   ├── providers/       # Wrapper providers for layout
│   └── routes/          # TanStack Router (Pages & Layouts)
│       ├── (auth)/      # Auth route groups
│       ├── (root)/      # Main page route groups
│       └── __root.tsx   # Main application layout
├── eslint.config.js     # ESLint configuration
├── package.json         # Dependencies & Scripts
├── tailwind.config.js   # Tailwind CSS configuration
├── vite.config.ts       # Vite configuration
└── README.md
```

#### UI Components

- **Common Folder**: Contains atomic components such as buttons, icons, or other reusable basic UI elements.
- **Mixins Folder**: Contains larger and more complex components that are combinations of several `Common` components, such as Navbar or Footer.

### Custom React Hooks

Several hooks are provided to speed up development:

- `useAxios`: To handle integrated API requests with Axios.
- `useClipboard`: To handle copy-to-clipboard functionality.
- `useDebounce`: To handle inputs that require delayed actions.
- `useHasMounted`: To detect if a component has mounted (client-side).
- `useMobileResponsive`: To detect mobile view.
- `useScreenSize`: To monitor screen size.
- `useSort`: To handle data sorting logic.
